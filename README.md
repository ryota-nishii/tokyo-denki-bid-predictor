# 電気工事 落札額予測アプリ（ドラフト版）

東京都電子調達システムの電気工事案件について、過去の入札結果から **落札率** と **落札額の目安** を予測する Streamlit アプリです。外部の積算会社に見積もりを依頼する前に、案件をふるい分けるための参考値を出すことを目的としています。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `data/bids.csv` | 学習データ（等級A・多摩地区の電気工事 51件。うち不調1件は学習から除外） |
| `features.py` | 特徴量の作成（学習とアプリで共通） |
| `train.py` | モデルの学習・評価。`model/` に学習済みモデルと評価結果を保存 |
| `predictor.py` | 学習済みモデルを読み込んで1件分を予測 |
| `app.py` | Streamlit の画面 |
| `model/model.joblib`, `model/metrics.json` | 学習済みモデルと評価結果 |

## 使い方

Mac の場合（Python 3.9 以上）:

```bash
cd bid-predictor
python3 -m venv .venv            # 仮想環境を作る（初回のみ）
source .venv/bin/activate        # 仮想環境に入る（ターミナルを開くたび）
python -m pip install -r requirements.txt
python train.py                  # 学習（データを追加したら再実行）
python -m streamlit run app.py   # アプリ起動（ブラウザが開く）
```

## モデル

- 目的変数：落札率（落札金額 ÷ 予定価格、いずれも税抜）
- 特徴量：予定価格（対数）、工期日数、公表区分、基準価格の種類、発注機関、工事内容区分
  - 入札者数・辞退数など、入札前に分からない項目は使わない
- 候補：基準モデル（基準価格の種類ごとの平均）、リッジ回帰、ランダムフォレスト、勾配ブースティング
- 評価：5分割×10回の交差検証の MAE と、開札日順の時系列分割（古い80%で学習・新しい20%でテスト）の MAE

## データの出典

東京都電子調達システム 入札情報サービス「入札(見積)経過情報」の画面から手作業で収集。落札者名など会社名は学習データに含めていません。利用規約の確認状況により、公開リポジトリにデータを含めてよいか事前に確認してください。

## デプロイ（Streamlit Community Cloud）

1. このフォルダを GitHub リポジトリにプッシュ
2. Streamlit Community Cloud で「New app」→ リポジトリと `app.py` を指定
3. Advanced settings の Python バージョンは初期値のままで可（起動時に scikit-learn のバージョンが学習時と違えば自動で学習し直します）
